Mok Para

Hlaing Shey Pyin · လှိုင်ရှည်ပြင်

Mok Para is a Rohingya village in U Kyaw (a) Thar Zin village tract, Buthidaung township, Maungdaw district, Arakan (Rakhine State, Myanmar). Its official romanised name is Hlaing Shey Pyin. In Burmese it is written လှိုင်ရှည်ပြင်. It lies at 20.7467° N, 92.5748° E.

What is FARA?

FARA, the Arakan Village Name Archive, preserves the names and locations of 1,023 Rohingya villages across Arakan in Rohingya, English and Burmese, so that those names are never erased.
